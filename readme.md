## 🚨 第一部分：初次使用新用户常犯的“五大高危死坑”

在数理逻辑上，系统是无懈可击的；但系统无法防御键盘前人类的“手痒”和“主观幻觉”。以下是 50 年内最容易引爆状态机溃决的人为操作：

### 1. 😭 刻舟求剑坑：第二个月忘记更新 `W_current`

* **现象**：5 月 28 日首航成功后，到了 6 月 28 日准备投第二笔钱。你只改了 `Target_Inflow_RMB`，没有去券商 App 看一眼真实持仓比例，直接让 `W_current` 带着全 `0` 的历史残渣再次运行。
* **代价**：系统会认为你当前依然是“零持仓”白纸状态，从而再次吐出一个**等比例平铺**的初始分配单。这会导致香农魔鬼引力场（Shannon's Demon）全盘失效，直接退化成无脑定投，彻底丧失高低纠偏的 Alpha 溢价。
* **风控防御**：每次运行前，**必须且唯一**要手动搬运的数据，就是你当前券商端真实的资产市值比例。

### 2. 💸 频繁强刷坑：资金量极小时盲目追求高频对冲

* **现象**：看到 15 天或 7 天运行一次能捕获更高的波动率，在每次到账资金只有几百块、甚至几十块钱时，频繁触发脚本并去券商端扣动扳机。
* **代价**：香港券商（盈立/致富）手动碎股单是有最低佣金门槛的（如每单 1~2 美元）。如果单次分配到 QQQM 或 URA 的资金只有几十元，佣金占比会瞬间飙破 **2% 甚至 5%**，高频再平衡带来的那点肉渣收益会被手续费和跨境换汇点差**静默蚕食、直接反噬**。
* **风控防御**：单次注入资金如果低于 **1500 RMB**，强制保持 30 天以上的长运行步长，拒绝高频摩擦。

### 3. 🧠 主观叛变坑：肉身对抗控制台指令

* **现象**：6 月份美股暴跌，半导体（SMH）跌成血海。Go 引擎在数理上判定其为绝对洼地，冷酷地下达了“将当月 80% 的资金全部砸进 SMH 抄底”的指令。你肉身看着满屏幕的恐慌新闻，主观产生动摇，擅自篡改指令，把钱平均分给了 QQQM。
* **代价**：你主动斩断了系统的反馈控制流。由于你拒绝在极值点装填子弹，等到 7 月半导体暴力反弹时，系统持仓将无法触发非线性爆发，你的最终资产号会发生**亿级级别的坍塌**。
* **风控防御**：**把肉身当成纯粹的执行硬件。** 键盘前不需要巴菲特，只需要一个绝对服从指令的 SRE 运维。

### 4. 💽 脏数据污染坑：手动篡改有状态持久化 JSON

* **现象**：不小心用文本编辑器打开了 `matrix_persistent_state.json`，手抖多敲了一个逗号，或者改动了里面的 `LastRunDate`。
* **代价**：由于 Roo 在上一轮重构中全面硬化了输入协议验证，JSON 的任何语法畸变都会导致系统的反序列化器（Unmarshal）直接报错。系统会直接触发 `FATAL` 阻断自愈，拒绝启动，直到你肉身把 JSON 语法修复。
* **风控防御**：对 persistent 文件执行绝对的“只读（Read-Only）”管理，禁止一切肉身编辑。

### 5. ⚡ 见证奇迹坑：在美股刚开盘的剧烈跳动期运行

* **现象**：憋到了周四晚上 21:35（美股刚开盘 5 分钟），兴奋地在 Mac 上敲下 `go run .`。
* **代价**：此时雅虎财经的日线 API 会把刚开盘、伴随着巨大噪音正在剧烈跳动的实时 Tick 数据塞进历史数组的最后一根 K 线。这会导致 $\delta_{macro}$ 在几分钟内上下巨幅漂移，你算出来的账单将充斥着开盘瞬时的随机噪音。
* **风控防御**：死守操作窗口，**永远在美股常规盘开盘前（国内时间 06:00 - 21:00 之间）运行**。

### 🚨 第三章：异常断电与网络脆断容灾预案（Emergency Playbook）

如果系统在运行过程中突然发生未知中断，依循以下 SRE 状态自愈协议：

* **场景一：运行 `go run .` 时由于网络阻断连续报错**
* **机制**：重构后的熔断器（Circuit Breaker）会在连续失败 3 次后强制 `log.Fatalf` 锁死，系统绝对不会生成任何错误的账单，也不会污染本地持久化 JSON。
* **对策**：肉身检查你的 Mac 网络，必要时切换代理，只要成功运行一次，连续异常计数器会自动秒级清零归零。


* **场景二：写文件的一瞬间 Mac 突然断电黑屏**
* **机制**：
* 状态文件采用 `TempFile -> Sync -> Rename` 原子替换，要么全是旧状态，要么全是新状态，绝对不会有一半的半截脏数据。
* 日志追加采用 `Seek + Truncate` 事务回滚，会自动将受损的文件截断恢复到最后一个完好的干净行。


* **对策**：重新开机，直接再次输入 `go run .` 重新点火。同日幂等守卫（Idempotency Guard）会自动判定今天是否已经成功写过盘。如果写过，会安全退出；如果没写过，会重新为你刷出最纯净的交割单。
